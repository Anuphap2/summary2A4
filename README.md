# A4 Summary & CheatSheet Studio (เครื่องมือทำสรุปสอบหน้า-หลัง อัจฉริยะ)

เว็บแอปพลิเคชันที่สร้างขึ้นด้วย **React + Vite** เพื่อให้นักศึกษาใช้จัดทำเอกสารสรุปสอบ (Cheat Sheet) ขนาดมาตรฐาน A4 แบบ 2 หน้า (หน้า-หลัง) พร้อมระบบ **Smart Chunking Engine** ที่ให้ผู้ใช้วางเนื้อหาดิบ (Raw Text) ทั้งก้อน แล้วระบบจะตัดแบ่งเป็นส่วน ๆ ลงในการ์ด A4 ให้โดยอัตโนมัติ

ออกแบบตามแนวทาง **Figma Design System** (`npx getdesign add figma`) และผ่านเกณฑ์การออกแบบระดับสูงของ **Impeccable UI** (`npx impeccable install`)

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **ระบบยัดข้อความดิบ & แบ่งท่อนอัจฉริยะ (Smart Chunking Engine)**:
   - วางเนื้อหาดิบ สไลด์ หรือเลกเชอร์ทั้งก้อน (Unstructured text / Markdown)
   - เลือกวิธีแบ่งท่อนเนื้อหาได้ 4 รูปแบบ:
     - **แบ่งตามหัวข้อ (Headings):** ตรวจจับ `#`, `##`, ตัวเลขข้อ `1.`, `2.`, หรือคีย์เวิร์ดภาษาไทย `บทที่`, `หัวข้อ:`
     - **แบ่งตามย่อหน้า (Paragraphs):** แยกตามการเว้นบรรทัด 2 ครั้ง
     - **แบ่งอัตโนมัติตามความยาว:** กำหนดความยาวตัวอักษรเป้าหมาย (~400 ตัวอักษร) พอดีกับ 1 กล่องสรุป A4
     - **กำหนดเครื่องหมายคั่นเอง:** เช่น คั่นด้วย `---` หรือ `===`
   - ตรวจจับสูตรคำนวณ (`... = ...`) แปลงเป็นกล่องสูตร monospace สวยงามอัตโนมัติ
   - หน้าต่างพรีวิวท่อนสรุป สามารถแก้ไขข้อความ, รวมกล่องที่ติดกัน (Merge), หรือลบกล่องก่อนนำเข้าได้
   - เลือกลง **"หน้า 1"**, **"หน้า 2"**, หรือ **"กระจาย 2 หน้าเท่าๆ กัน (Auto-balance)"** ได้ทันที

2. **กระดาษ A4 เสมือนจริง & สลับแนวตั้ง-แนวนอน (Portrait & Landscape Orientation)**:
   - ปรับสลับระหว่าง **"แนวตั้ง" (Portrait 210 x 297 mm)** และ **"แนวนอน" (Landscape 297 x 210 mm)** ได้ทันทีจากปุ่มบน Navbar
   - **มาตรวัดความจุของแผ่น A4 (Height Overflow Meter):** แจ้งเตือนแบบเรียลไทม์หากเนื้อหายาวเกิน 1 แผ่น A4 (เตือนสีแดง) คำนวณความสูงตามแนวตั้ง/แนวนอนอย่างแม่นยำ ช่วยป้องกันการถูกตัดบรรทัดเมื่อสั่งพิมพ์
   - ปรับเลย์เอาต์คอลัมน์ได้อิสระในแต่ละหน้า:
     - **แนวตั้ง:** 1 คอลัมน์, 2 คอลัมน์ (แนะนำ), 3 คอลัมน์
     - **แนวนอน:** 1 คอลัมน์, 2 คอลัมน์, 3 คอลัมน์ (แนะนำ), 4 คอลัมน์ (อัดแน่นเป็นตาราง)
   - มุมมองเปรียบเทียบหน้า-หลัง (Side-by-Side Dual Page) หรือมุมมองเลื่อนแนวตั้ง (Stacked) พร้อมแถบซูม 60% – 140%

3. **การ์ดสรุปเนื้อหาปรับแต่งได้อิสระ (Modular Cheat Sheet Cards)**:
   - แก้ไขข้อความในแต่ละกล่องได้โดยตรง (Inline Editing)
   - กล่องสมการสูตรคำนวณความคมชัดสูง (`[formula]...[/formula]`)
   - ระบบแท็กและธีมสีพาสเทลตาม Figma Palette: `Lime`, `Lilac`, `Mint`, `Coral`, `Cream`, `Pink`, และ `Monochrome`
   - ลากย้ายตำแหน่งการ์ด (Drag & Drop), เลื่อนขึ้น-ลง, ทำซ้ำ, ย้ายข้ามหน้า 1 ↔ หน้า 2

4. **การปรับขนาดตัวอักษรสำหรับข้อสอบ (Font Density Modes)**:
   - **จิ๋วมาก (8.5px):** อัดแน่นสูงสุดสำหรับข้อสอบที่อนุญาตกระดาษสรุปแผ่นเดียว
   - **ปกติ (9.5px):** สมดุล พอดี 2 หน้า A4 อ่านง่าย ชัดเจน
   - **สบายตา (10.5px):** ขนาดใหญ่ เหมาะสำหรับอ่านทบทวนก่อนสอบ

5. **ระบบพิมพ์และส่งออกเอกสาร (Print & Export)**:
   - ปุ่ม **"พิมพ์ / PDF"** พร้อม CSS `@media print` สำหรับสั่งพิมพ์ลงกระดาษ A4 หรือบันทึกเป็น PDF เป๊ะ 100% ไม่มี UI หรือขอบรบกวน
   - สำรองข้อมูลและกู้คืนด้วยไฟล์ **JSON**
   - ส่งออกเป็นไฟล์ **Markdown (.md)**

## 🚀 วิธีเริ่มใช้งานในเครื่อง (Getting Started)

```bash
# 1. ติดตั้งแพ็กเกจ (หากยังไม่ได้ติดตั้ง)
npm run build

# 2. เริ่มต้น Dev Server
npm run dev
```

เปิดเบราว์เซอร์ไปที่: `http://localhost:5173`

---

## ⌨️ คีย์ลัด (Keyboard Shortcuts)
- **Ctrl + S / Cmd + S**: บันทึกการแก้ไขลงเบราว์เซอร์ทันที
- **Ctrl + P / Cmd + P**: สั่งพิมพ์ใบสรุปเป็น A4 หรือ PDF

## 📁 โครงสร้างโปรเจกต์
- `src/App.jsx`: ศูนย์ควบคุม State, การกระจายท่อนเนื้อหา, การจัดเก็บ LocalStorage
- `src/components/RawTextImporterModal.jsx`: เครื่องมือยัดข้อความดิบ และ Smart Chunking Engine
- `src/components/A4Page.jsx`: คอมโพเนนต์แผ่นกระดาษ A4 และระบบวัด Overflow
- `src/components/CardItem.jsx`: การ์ดสรุปพร้อมกล่องสูตรและพาเลตสีพาสเทล Figma
- `src/components/Navbar.jsx`: แถบควบคุมบนสุดสไตล์มินิมอล Figma
- `src/data/defaultData.js`: ข้อมูลตั้งต้นจากต้นแบบเดิม (สูตรคำนวณ, AI, ภาพดิจิทัล, หุ่นยนต์)
