⠿ 🧮 1. รวมสูตรคำนวณสำคัญ (K-NN, ขนาดไฟล์, คลื่น)
• K-NN Distance (Euclidean):
d = √[ (x₂ - x₁)² + (y₂ - y₁)² ]
- 1-NN: วัดระยะห่างไปยังทุกจุด จุดไหนใกล้สุด ตอบประเภทนั้นทันที
- 3-NN: เลือกเพื่อนบ้านที่ใกล้สุด 3 ลำดับแรก แล้วตัดสินด้วยเสียงข้างมาก (Majority Vote)
- โจทย์ข้อสอบ: ทำนายประเภทหนัง (ฉากต่อสู้ x, ฉากรัก y) คำนวณ d เทียบตาราง
• สูตรคำนวณขนาดไฟล์ภาพ (Raw Size):
ขนาดไฟล์ (Bits) = กว้าง(W) × ยาว(H) × Bit Depth
- สเต็ปแปลงหน่วย: Bits ÷ 8 = Bytes → ÷ 1,024 = KB → ÷ 1,024 = MB
- ความลึกบิต: ขาวดำ (Binary) = 1 บิต, เทา (Grayscale) = 8 บิต, สี (RGB) = 24 บิต (8×3)
- ตัวอย่าง 512×512: ขาวดำ = 0.033 MB, Grayscale = 0.262 MB, RGB = 0.786 MB
• คลื่นแสง & สัญญาณดิจิทัล:
F = 1 / T | T = 1 / F | V = F × λ | ความเร็วแสง V = 3 × 10⁸ m/s
- Nyquist Theorem: ความถี่สุ่ม fs ≥ 2 · fmax ป้องกันสัญญาณเพี้ยน (Aliasing)
⠿ 🖼️ 2. ภาพดิจิทัล & เทคนิคการปรับปรุงภาพ
• การแปลง Analog → Digital:
1. Sampling: สุ่มตำแหน่งพิกัดเชิงพื้นที่กลายเป็นพิกเซล (X, Y)
2. Quantization: แปลงความเข้มแสงเป็นระดับตัวเลข (Gray Level เช่น 0–255)
• 4 ชนิดของภาพดิจิทัล:
- Binary (1-bit): มีแค่ 0 (ดำ) และ 1 (ขาว) ขนาดเล็กสุด เหมาะกับตัวหนังสือ/ลายนิ้วมือ
- Grayscale (8-bit): 256 ระดับเทา (0 = ดำสนิท, 255 = ขาวสว่าง)
- True Color RGB (24-bit): สีแดง-เขียว-น้ำเงิน ช่องละ 8 บิต รวม 16.7 ล้านสี
- Indexed Color: เก็บดัชนี 8 บิต อ้างอิง Color Table ไม่เกิน 256 สี นิยมใน GIF
• Bitmap vs Vector:
- Bitmap: สร้างจากพิกเซล ขยายแล้วแตก/เบลอ ภาพถ่ายสมจริง ไฟล์ใหญ่ตาม Resolution
- Vector: สร้างจากสมการคณิตศาสตร์/เรขาคณิต ขยายเท่าไรก็คมชัด ไฟล์เล็ก เหมาะกับโลโก้
• 4 เทคนิคปรับแต่งภาพ (ออกสอบแน่):
1. Anti-aliasing: เกลี่ยจุดสีรอยต่อเพื่อลบรอยหยัก ให้ขอบเส้นดูเรียบเนียน
2. Transformation: แปลงเชิงเรขาคณิต เช่น ย่อ/ขยาย หมุน เลื่อนตำแหน่ง ปรับสว่าง
3. Dithering: กระจายจุดสีหลอกสายตาเพื่อจำลองเฉดสีใหม่เมื่อจอมีสีจำกัด
4. Rendering: ลงสี คำนวณแสง เงา และพื้นผิวลงบนโครงร่างโมเดล 3D ให้สมจริง
⠿ 🎨 3. ระบบแม่สี & ภาพเคลื่อนไหว (Animation)
• ระบบแม่สี Additive vs Subtractive:
- Additive (ระบบแสง 3 สี): แม่สี RGB (แดง เขียว น้ำเงิน) รวมกันทุกสี = สีขาว ไม่มีแสง = สีดำ ใช้กับจอแสดงผล คอมพิวเตอร์ ทีวี
- Subtractive (ระบบสารสี 4 สี): แม่สี CMYK (ฟ้า-Cyan, ม่วงแดง-Magenta, เหลือง-Yellow, ดำ-Key/Black) รวมทุกสี = สีดำ ไม่มีสี = สีขาว ใช้กับงานพิมพ์ เครื่องพิมพ์
• ความสว่าง, คอนทราสต์ & Point Processing:
- Brightness (B): ค่าเฉลี่ยความสว่าง B = (1/MN) × Σ f(x, y)
- Contrast (C): ส่วนเบี่ยงเบนมาตรฐานของการกระจายแสง C = √[ (1/MN) × Σ(f(x, y) - B)² ]
- ปรับเชิงเส้น: g(x, y) = a · f(x, y) + b (a ปรับคอนทราสต์, b ปรับสว่าง)
- Image Negative: g(x, y) = 255 - f(x, y) (สลับดำเป็นขาว ขาวเป็นดำ)
• ภาพเคลื่อนไหว (Animation Costs):
- ถูกสุด / เร็วสุด: Computer Animation (2D/3D ดิจิทัล แก้ไขง่าย ลดต้นทุน)
- แพงสุด / ใช้เวลานานสุด: Traditional Hand-drawn (วาดมือทีละเฟรม 24 รูป/วินาที ใช้คนมหาศาล) และ Stop Motion คุณภาพสูง
⠿ 🔍 4. การจำรูปแบบ & การคิดเชิงนามธรรม
• นิยาม Pattern Recognition:
- Pattern Recognition: ศาสตร์จำแนกวัตถุออกเป็นหมวดหมู่ (Classes) ตามรูปแบบ
- Feature: คุณลักษณะเด่นเชิงปริมาณ/คุณภาพที่เป็นตัวแทนของข้อมูล
- Feature Extraction: การสกัดดึงฟีเจอร์เด่นออกจากข้อมูลดิบ
- Feature Selection: การคัดเลือกฟีเจอร์ที่ดีที่สุดเพื่อใช้จำแนกอย่างแม่นยำ
- Classifier: ฟังก์ชัน/ตัวตัดสินใจจัดวัตถุเข้าสู่ Class
- Label: ป้ายกำกับเฉลยชื่อคลาสข้อมูล
• Abstraction (การคิดเชิงนามธรรม):
- กระบวนการคัดกรอง โฟกัสเฉพาะสาระสำคัญที่เป็นแก่นของปัญหา และตัดรายละเอียดที่ไม่จำเป็นหรือฉากหลัง (Background) ทิ้งไป
- ตัวอย่าง: ภาพคนเล่นเครื่องรอกออกกำลังกาย (Cable Press) สนใจแค่กลไกระบบรอก ตัดตัวคนและบรรยากาศในฟิตเนสทิ้ง
• 4 ทักษะแนวคิดเชิงคำนวณ (Computational Thinking):
1. Decomposition: แตกปัญหาใหญ่ออกเป็นปัญหาย่อยๆ
2. Pattern Recognition: สังเกตรูปแบบ ความเหมือน ความต่าง และแนวโน้ม
3. Abstraction: ตัดสิ่งที่ไม่จำเป็น สนใจเฉพาะสาระสำคัญ
4. Algorithm Design: ออกแบบขั้นตอนแก้ปัญหาแบบเป็นลำดับขั้น

⠿ 🤖 5. วิทยาการหุ่นยนต์ (Robotics)
• 5 องค์ประกอบพื้นฐานหุ่นยนต์:
1. Mechanical: กลไก โครงสร้าง และฮาร์ดแวร์
2. Power: แหล่งจ่ายพลังงาน เช่น แบตเตอรี่, ไฟเลี้ยง
3. Sensor: ส่วนรับรู้สิ่งแวดล้อม (ตา-กล้อง, หู-ไมค์, ผิว-สัมผัส/เคมี)
4. Effector / Actuator: ส่วนกระทำตอบสนอง เช่น แขนกล มอเตอร์ ล้อ
5. Intelligent / Control System: สมองกลประมวลผลและการตัดสินใจ
• สถาปัตยกรรมระบบควบคุม:
- Reactive Control: รับข้อมูลจาก Sensor สั่งงาน Effector ทันที ไม่มี AI ไม่มีความจำ ไม่เก็บอดีต ตอบสนองรวดเร็วในสภาพแวดล้อม Dynamic
- Subsumption Architecture: นำ AI มาใช้ (ANN, Fuzzy, GA) วางแผนได้ และ เก็บบันทึกข้อมูลอดีตเป็นประสบการณ์ (ต้องใช้แรมเยอะ)
• ประเภทหุ่นยนต์ (คำศัพท์ข้อสอบ):
- Fixed Robot: หุ่นยนต์อยู่กับที่ เช่น แขนกลโรงงาน (Robotic Arm)
- Mobile Robot: เคลื่อนที่ได้ (ล้อ, ล้อสายพาน, ขา, บิน, ว่ายน้ำ)
- Humanoid: หุ่นยนต์รูปร่างเลียนแบบมนุษย์ทั้งตัว เช่น ASIMO
- Cyborg (ไซบอร์ก): สิ่งมีชีวิตที่มีชิ้นส่วนจักรกล/อิเล็กทรอนิกส์ฝังในร่างกาย
- Actroid (แอคทรอยด์): ฮิวแมนนอยด์ที่เน้นความเหมือนมนุษย์จริงขั้นสูง ทั้งผิวสัมผัสและการแสดงสีหน้า (มักเลียนแบบผู้หญิง)
- Nanorobot (นาโนโรบอต): ขนาดระดับนาโนเมตร ใช้ในการแพทย์ระดับเซลล์
• ภาษาโปรแกรมหุ่นยนต์:
- Behavior Language: (Rodney Brooks, 1990) ใช้ Rule-Based แบบ Real-time กับ Subsumption
- GRL: Functional programming สำหรับ Finite State Machine
- Alisp: พัฒนาจาก Lisp ช่วยให้หุ่นยนต์ตัดสินใจได้เองจากการเรียนรู้
⠿ 🧠 6. โครงข่ายประสาทเทียม & Deep Learning
• เทียบโครงข่ายชีววิทยากับคอมพิวเตอร์:
- เดนไดรท์ (Dendrite) = ข้อมูลนำเข้า (Inputs: xᵢ)
- จุดประสานประสาท (Synapses) = ค่าน้ำหนักความสำคัญ (Weights: wᵢ)
- เซลล์ประสาท (Neuron/Soma) = ผลรวมถ่วงน้ำหนัก (Summation: Σ wᵢxᵢ) + Activation Function
- แอ็กซอน (Axon) = ผลลัพธ์ขาออก (Output: y)
• สถาปัตยกรรม & การปรับค่าน้ำหนัก:
- Feedforward: ข้อมูลวิ่งไปข้างหน้าทิศทางเดียว Input → Hidden → Output
- Feedback (Recurrent): มีการป้อนผลลัพธ์ย้อนกลับมาคำนวณซ้ำ
- Backpropagation: อัลกอริทึมส่งค่า Error ย้อนกลับจาก Output ด้วยวิธี Gradient Descent เพื่อคำนวณปรับ Weight (Δw)
• Activation Functions (ฟังก์ชันกระตุ้น):
- Binary Step / Threshold: ตัดค่าเป็น 0 หรือ 1 ตามขีดเริ่มเปลี่ยน T
- Sigmoid (S-curve): f(x) = 1 / (1 + e⁻ˣ) บีบค่าช่วง [0, 1] กราฟตัว S
- ReLU: f(x) = max(0, x) ถ้าลบปัดเป็น 0 ถ้าบวกคงเดิม แก้อาการ Vanishing Gradient นิยมที่สุดใน Deep Learning
- Softmax: บีบเอาต์พุตหลายโหนดเป็นความน่าจะเป็น รวมกันได้ 1 (100%)
• คำศัพท์เฉพาะทาง Deep Learning:
- Epoch: รอบการเทรนที่โมเดลเรียนรู้ผ่านชุดข้อมูล Training Data ครบทุกตัวอย่าง 1 รอบเต็ม
- CNN (Convolutional Neural Network): สกัด Spatial Features เหมาะที่สุดกับ งานภาพ (Image Processing / Computer Vision)
⠿ 📚 7. รูปแบบการเรียนรู้ (Machine Learning)
• 1. Supervised Learning (แบบมีผู้สอน):
- ข้อมูลมีทั้ง Feature และ Label (เฉลยเปรียบเหมือนมีครูคอยตรวจคำตอบ)
- โมเดลจะตรวจเช็กคำตอบกับเฉลยเพื่อปรับแก้ Weight ให้ดีขึ้น (เช่น Classification, Regression)
• 2. Unsupervised Learning (แบบไม่มีผู้สอน / Clustering):
- ข้อมูลไม่มี Label หรือเฉลยล่วงหน้า
- โมเดลต้องหาความสัมพันธ์และจัดกลุ่มก้อนข้อมูลเองตามความคล้ายคลึง (เช่น การแบ่งกลุ่มสายพันธุ์พืช/สัตว์)
• 3. Semi-supervised Learning:
- ใช้ข้อมูลที่มี Label จำนวนน้อย ผสมกับข้อมูลไม่มี Label จำนวนมาก เพื่อช่วยประหยัดเวลาและต้นทุนการเตรียมข้อมูล
• 4. Reinforcement Learning (การเรียนรู้เสริมกำลัง):
- เรียนรู้ผ่านการลองผิดลองถูก (Trial & Error)
- ตัว Agent จะเรียนรู้กับสภาพแวดล้อมโดยได้รับ "รางวัล (Reward)" เมื่อทำถูก และ "บทลงโทษ (Penalty)" เมื่อทำผิด
⠿ 💡 8. ระบบผู้เชี่ยวชาญ & การจัดการข้อมูล
• ระบบผู้เชี่ยวชาญ (Expert System - ES):
- โปรแกรมจำลองการตัดสินใจของผู้เชี่ยวชาญเฉพาะทางโดยใช้ความรู้และการอนุมาน
- 5 ส่วนประกอบหลัก:
1. Knowledge Base: ฐานความรู้และกฎเกณฑ์ (IF-THEN)
2. Inference Engine: เครื่องอนุมาน กลไกประมวลผลตรรกะเพื่อหาข้อสรุป
3. Knowledge Acquisition: ส่วนดึง/ถ่ายทอดความรู้จากคนมาใส่ระบบ
4. Explanation Subsystem: ส่วนอธิบายเหตุผลว่าทำไมถึงตอบเช่นนั้น
5. User Interface: ส่วนติดต่อประสานงานกับผู้ใช้งาน
• เปรียบเทียบประเภทระบบ ES:
- Rule-based: ใช้ตรรกะกฎชัดเจนตรงไปตรงมา IF (เงื่อนไข) THEN (ผลลัพธ์)
- Fuzzy Expert System: ใช้ตรรกศาสตร์คลุมเครือ ค่าความจริงอยู่ในช่วง [0, 1] สำหรับจัดการข้อมูลกำกวม เช่น "น้ำอุ่นปานกลาง", "รถวิ่งเร็วมาก"
- Case-based Reasoning (CBR): แก้ปัญหาใหม่โดยเทียบเคียงกับกรณีศึกษา/ประสบการณ์เดิมในอดีตที่คล้ายกัน
• ลักษณะเฉพาะของระบบ & ข้อมูล:
- Deterministic: ผลลัพธ์แน่นอน 100% ป้อนค่าเดิมได้ผลเดิมเสมอ ไร้การสุ่ม
- Probabilistic (Stochastic): มีความน่าจะเป็น/ความไม่แน่นอนเข้ามาเกี่ยวข้อง
- Static System: ผลลัพธ์ขึ้นกับอินพุตปัจจุบันเท่านั้น ไม่มีความจำอดีต
- Data Mining: การค้นหารูปแบบหรือความรู้ที่ซ่อนอยู่ในฐานข้อมูลขนาดใหญ่
